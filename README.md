# ATM-Banking-System-Simulation-JavaScript

A beginner-level JavaScript program that simulates an ATM system with passkey-based login authentication. The application allows users to check account balance, deposit money, withdraw funds, and exit the program using text-based menu options.

This project focuses on practicing core JavaScript concepts such as loops, conditional logic, input handling, state management, and basic user authentication. It was built for learning and logic-building purposes using browser prompts and alerts.
